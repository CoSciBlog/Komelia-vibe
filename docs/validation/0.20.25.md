## Review and limits

Google Translate assisted the missing resource entries. Existing translator work
was retained; primary UI terminology, German wording, all plural forms and detected
untranslated English phrases received additional review. This is resource and
format coverage validation, not a claim of native-speaker certification of every
sentence. Proper names, technical codes, user-edited labels, book metadata and
server diagnostics retain their original content.

No Android device/emulator install or UI test was performed. Desktop/browser
runtime behavior beyond the Compose JVM test was not exercised; their affected
code was compiled. Windows/Linux packages are not rebuilt for this Android release.
Material OpenAI Codex assistance and original project attribution are disclosed
in the release notes and project credits.

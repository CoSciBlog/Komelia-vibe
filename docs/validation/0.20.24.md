# App language validation — 0.20.24

Focused scope: persisted app language, upgrade compatibility, live resource
refresh, Appearance translations and the directly affected shared targets.
Feature request: https://github.com/CoSciBlog/Komelia-vibe/issues/60.

- `:komelia-infra:database:sqlite:jvmTest --tests snd.komelia.db.settings.AppLanguageSettingsTest`:
  **2 tests passed**. Run all existing app migrations before V15 against SQLite,
  preserve prior preferences, round-trip every language through reopened repositories,
  restore System for an unknown database tag, and decode old browser JSON settings.
- `:komelia-ui:jvmTest --tests snd.komelia.ui.platform.AppLanguageEnvironmentTest`:
  **1 test passed**. Compose switches System/German → English → German → Chinese
  → System while refreshing Appearance and update strings and retaining remembered
  UI state. Initial test-harness failures were corrected by providing density,
  a frame clock and snapshot notification processing.
- `python cmake/verify-app-language-resources.py`: **70 translations in 7 locales
  passed**, with unique keys and nonempty picker, Appearance and navigation strings.
  The same command supports `--apk` for inspection of the shipped resource bytes
  and inclusion of migration V15.
- JVM UI/database and Android release Kotlin compilation passed.
- UI and shared browser WebAssembly compilation passed; both were checked because
  serialized settings gained a field.
- `:komelia-app:androidApp:assembleRelease :komelia-app:androidApp:lintRelease`:
  **passed**. No application-wide suite was needed for this isolated change.
- `git diff --check`: **passed**.

Android resource API inspection confirmed that Compose Resources 1.12 reads the
default locale as well as the localized configuration. The Android provider sets
both, including for resource reads outside composition. Android assembly/lint
are repeated after this platform-specific correction.

Gradle commands use `--no-configuration-cache --console=plain -x buildEpubReaders`.
Unchanged native libraries, EPUB reader assets and component legal files were
reused from the verified, published 0.20.23 universal APK. The final package must
pass the repository's complete APK verifier, certificate continuity, ZIP alignment,
byte comparisons against those inputs, language-resource verification and uploaded
asset hashes. APK assembly is run again from the final source commit, reusing
successful focused checks for unchanged code.

No Android device or emulator was connected (`adb devices` returned an empty
list), so no device UI/install test was performed. Desktop/WebAssembly runtime
interaction beyond the Compose JVM test was not exercised. Windows and Linux
distribution packages are not rebuilt. Other pages can still fall back to English
where translations were already missing; this change translates Appearance and
adds explicit app-wide language selection.

Implementation, tests, translations and release work received material assistance
from OpenAI Codex; original project attribution and component notices are retained.
